## Featured Projects

### [Research Radar](https://github.com/Pavan67u/research-radar)
Research-paper discovery application built with FastAPI, PostgreSQL, SQLAlchemy/Alembic, Next.js, and OpenAlex. It ingests scholarly metadata, normalizes papers/authors/topics, and finds related papers using TF-IDF similarity.

**Technologies:** Python · FastAPI · PostgreSQL · Next.js · OpenAlex · TF-IDF · Docker

### [Smart Traffic Monitoring System](https://github.com/Pavan67u/smart_traffic)
Computer-vision traffic monitoring pipeline. Uses YOLOv8 for vehicle detection, ByteTrack for tracking, and rule-based checks for traffic violations. Stores violation records and supporting evidence, with a Flask dashboard and data export.

**Technologies:** Python · YOLOv8 · OpenCV · ByteTrack · Flask · SQLite · Docker

### [Document QA Assistant](https://github.com/Pavan67u/doc-qa-assistant)
Full-stack PDF question-answering application. Extracts PDF text, creates embeddings, retrieves relevant passages using FAISS, and generates answers with Gemma 2:9B through Ollama. Includes a React frontend and conversation history.

**Technologies:** Python · FastAPI · React · FAISS · Sentence Transformers · Gemma · RAG

### [SideQuest](https://github.com/Side-Quest1/side-quest)
Cross-platform activity discovery and coordination prototype. Web and mobile applications share domain logic and UI packages. Implemented flows include activity discovery and creation, join requests, capacity visibility, and mock-backed group coordination. Authentication, persistent backend storage, realtime messaging, and Supabase integration are future backend work.

**Technologies:** Next.js · React Native · Expo · TypeScript · Shared Packages

### [Expense Tracker](https://github.com/Pavan67u/expense-tracker)
Personal finance application with transactions, budgets, debt tracking, savings goals, recurring transactions, bill reminders, analytics, search, and CSV export.

**Technologies:** React Native · Expo · Node.js · Express · PostgreSQL · Clerk

### [File Management System](https://github.com/Pavan67u/file-management)
Web-based file management and retrieval application with file uploads, keyword-based retrieval, and search/filter functionality.

**Technologies:** PHP · MySQL · HTML · CSS · JavaScript
